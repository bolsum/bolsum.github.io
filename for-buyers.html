What to send

Give us enough information to make the first conversation useful.

  • Product category and reference images
  • Tech pack, measurement chart or existing sample details — if available
  • Estimated quantity and colour breakdown
  • Target price and target market/currency
  • Required delivery or launch date
  • Any fabric, GSM, composition, wash, print or embroidery requirements

No tech pack yet? That is fine. Send the idea, reference image or sample description and we can start from there.
